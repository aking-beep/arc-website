# Brag Plan: ARC agent check

Render is held. `docs/BRAG-LAUNCH-PLAN.md` is the contract. The launch-readiness checklist in that file is not met, and the only honest film is the 22-second cut below. Do not render a platform announcement.

## What is this app?

ARC publishes a free alpha that grades a pasted description of agents against 19 deterministic rules, and a six-question checklist that refuses to treat a finished run as a finished job. Agent Control is not for sale.

## The angle

Proof, not a launch. The hook is the product's own contradiction: the run completed, and that is not the outcome.

## Hook (first 2–3 seconds)

Black frame. One line: "The agent said it finished."

## Key moments

- Split: a completed run on the left, the question "what changed" on the right.
- Three checklist lines, held long enough to read.
- The real Agent Governance empty state: 19 rules, nothing stored, alpha.

## Outro / punchline

ARC. "We check the system that was supposed to change."

## User flow worth showing

Paste a sanitized description → rules match statements → findings quote the input. If a recording is made, use the app's own example and label it SAMPLE. Do not type a real secret.
