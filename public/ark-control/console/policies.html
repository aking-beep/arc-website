Policies

Every matching policy is evaluated and the strictest effect wins, so adding a policy can only tighten authorization, never loosen it. A policy that matches but whose rules do not fire falls through to its own fallback — there is no path on which no policy decides.

    ALLOW
  3. ↳ Fallback

    if no rule matched: unclassified repository write
